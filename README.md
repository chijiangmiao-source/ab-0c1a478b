# 离线航迹交换站 · 可恢复航点索引

浏览器页面完成全部计算，IndexedDB 持久化；阶数 4 的 B+ 树对受影响路径写时复制（COW），
按「**新页 → 批次意图 → 根指针**」三阶段落盘。任何阶段断电后重开，可查询的航点索引
**只停在旧根，或发布一棵能从根完整遍历的新树**——半写入页绝不混入查询视图。

## 运行

需要 Docker Compose v2（站点与健康检查无需构建镜像；verify 容器仅用 `node:20-alpine`）：

```bash
docker compose up site          # 静态站点 http://localhost:8080 ，健康响应 /health
docker compose run --rm verify  # 规则测试 + 页面构建检查 + HTTP 冒烟，退出码交付结论
# 或一步完成（verify 依赖 site 健康检查通过后才启动）：
docker compose up --build --abort-on-container-exit --exit-code-from verify
```

无 Docker 时的本地等价检查（Node ≥ 20，无需安装依赖）：

```bash
node --test test/                       # 规则测试
node verify/build-check.mjs ./site      # 页面构建检查
# 另起任意静态服务器指向 site/（须提供 /health -> 200 ok），再：
SITE_URL=http://localhost:8080 node verify/http-smoke.mjs
```

## 数据模型与规则

- **页是不可变对象，页标识 = 页体 SHA-256 摘要**（内容寻址）。叶页 `{t:'l',k,v,n,g}`，
  内部页 `{t:'i',k,c,g}`，`g` 为该页最后一次被复制时的根代次。
- 阶数 4：每叶/内部页至多 3 键（4 个子页）；叶溢出时均衡分裂（4→2/2），右叶首键
  作为分隔键上浮（右叶保留副本）。删除时空叶摘除、单儿子内部层坍缩；不做借并，
  键数下限放宽到 1（≤24 键规模下结构简单且结论明确）。
- 编辑沿单条根→叶路径在内存中生成「骨架」，定稿时：
  1. 中序展平全部叶，**从右向左**统一重接 `next`（新叶改 id 会沿前驱链级联复制，
     右侧页永不被波及）；
  2. 自底向上重渲染内部页：子页集合未变的页以旧代次重建，内容寻址返回原 id，
     因此真正被复制的只有受影响路径（含必要的叶链闭包）。
- 全库至多 **24 个互异整数键**，短文本载荷 ≤120 字；每批稳定批次标识 + **至多 12 项**
  insert/update/delete，批次内键不得重复。

## 三阶段持久化与恢复真值表

| 阶段 | 已持久化证据 | 重开结论 |
|---|---|---|
| 1 新页写入中途 | 部分新页（可能连清单都没有） | **旧根**：残页从旧根不可达，清除 |
| 1 新页+清单完成 | 新页齐全 + staging，无 intent | **旧根**：证据不足，不发布 |
| 2 意图留下 | staging + intent，根仍在旧基 | 候选树可完整遍历 → **新根（前滚）**；缺页/损坏 → **旧根（回滚）** |
| 3 根切换后 | 根已指候选根 | 新树必须完整；补齐回执与清理，确认**新根** |

恢复只依据持久化证据：候选树通过完整性校验（摘要自洽、引用闭合、容量/扇出、
分隔键、叶链与树遍历同一组叶页、每键恰好一次）才允许前滚；否则一律保留旧根。

## 冲突与损坏（拒绝且根不变）

- 同批次标识 + 等价编辑重传 → **回放原回执**（回执标识一致），不产生新代次；
- 同批次标识但编辑内容不同（指纹不符）→ `BATCH_DIVERGED`，拒绝；
- 重复键插入、更新/删除不存在键、批次内重复键、超项、空批次 → 逐条给出中文原因；
- 已发布根存在页摘要不符（损坏/篡改）或子页引用无法闭合 → 拒绝执行并报告
  `DIGEST_MISMATCH` / `DANGLING_PAGE`，绝不切换根。

## 结果页展示

根代次、可达页数（叶/内部）、树深、叶序列键数、仓储存页数、根摘要；
按键有序的叶序列（含所属叶页与页代次）与显式的「**分裂后所有键仍恰好一次出现**」核对徽标；
可达页清单与各批次回执（基代次→根代次、编辑数、回执标识）；中断演习后的恢复结论
逐条列出（保留旧根 / 发布完整新根 / 丢弃过期意图）及原因。

页面勾选「在选定持久化阶段后模拟断电」后使用内存后端，可在
阶段 1 中途（可选只写入 N 页）/阶段 1 完成/阶段 2/阶段 3 四个断点中断，
随后视图停在旧根，点击「重开复核」查看裁决。
